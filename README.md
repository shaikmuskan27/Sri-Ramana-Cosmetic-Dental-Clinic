# Sri Ramana Cosmetic Dental Clinic

Official website for **Sri Ramana Cosmetic Dental Clinic**, located in Srinivasa Nagar, Nandyal, Andhra Pradesh. Led by **Dr. Sri Ramana, MDS, BDS**, Chief Aesthetic Dentist and Ceramic Implantologist with over 20 years of clinical experience.

## ✨ Highlights & Features
- **Modern Luxury Aesthetics**: Responsive design styled with bespoke dental clinical branding and typography.
- **Provided Services**:
  - **Cosmetic Dentistry**: Treatments for smile makeovers and aesthetics (veneers, bonding, smile designing).
  - **Ceramic & Dental Implants**: Metal-free, hypoallergenic biocompatible fixed teeth solutions.
  - **Laser Procedures**: Advanced minimally invasive soft-tissue laser treatments and teeth whitening.
  - **Routine Care**: General check-ups, ultrasonic cleaning, and preventive maintenance.
- **Direct Appointment Scheduling**: Interactive booking form with instant confirmation.
- **Clinic Video & Virtual Tour**: High-definition facility overview and doctor introduction.
- **Direct Payment & Receipt Generation**: Seamless UPI and digital payment simulator with downloadable receipt generation.
- **Interactive Google Maps & Helpline**: Direct contact channels, emergency lines, and location guidance.

## 🚀 Live Preview / Setup
Open `index.html` (or `code.html`) in any modern browser, or run a local static web server:
```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
Navigate to `http://localhost:3000/`.
